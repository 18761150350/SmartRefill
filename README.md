# 智能补货计算系统

这是一个基于 Blazor WebAssembly 开发的现代化智能补货计算系统，支持 Excel 文件上传、数据分析和容量约束管理。

## 🚀 系统特性

- ✅ Excel 文件上传和解析 (.xlsx, .xls)
- ✅ 智能补货量计算
- ✅ **机器最大容量约束管理**
- ✅ 自动应用补货历史时间
- ✅ 手动调整和容量预警
- ✅ 现代化用户界面设计
- ✅ 跨平台支持（Windows, macOS, Linux, Android, iOS）
- ✅ 移动设备友好界面

## 🎯 核心功能

### 智能补货算法
- **基础补货**：根据销售数据计算基本补货需求
- **智能调整**：基于销售趋势预测的智能调整量
- **手动调整**：用户可自定义调整补货量
- **容量约束**：确保补货量不超过机器最大容量

### 最大容量约束管理
- 智能调整自动受限于最大容量（可为负数以平衡）
- 手动调整超出容量时显示红色警告
- 实时容量剩余显示和提示
- 总计超出容量时进行可视化标记

### 历史时间应用
- 自动读取补货历史文件
- 一键应用历史补货时间到所有机器
- 支持手动设置补货时间
- 灵活的时间格式支持

### 使用流程
1. **上传文件**：选择交易记录Excel文件
2. **可选历史**：上传补货历史文件（自动应用时间）
3. **检测机器**：系统自动识别机器信息
4. **设置时间**：确认或调整补货时间
5. **开始计算**：生成智能补货建议
6. **调整数量**：根据需要手动调整补货量
7. **导出结果**：复制或下载计算结果

## 📊 算法说明

### 容量约束逻辑
```
1. 基础补货 = 根据销售需求计算
2. 智能调整 = 基于趋势预测，受最大容量限制
3. 如果 基础补货 + 智能调整 > 最大容量：
   智能调整 = 最大容量 - 基础补货 (可能为负数)
4. 手动调整 = 用户输入，超出容量时显示警告
5. 总计 = 基础补货 + 智能调整 + 手动调整
```

### 产品配置
- **BM (Bonaqua)**：最大容量 120个，箱规 24个/箱
- **EM (Evian)**：最大容量 180个，箱规 24个/箱  
- **ES (Evian Small)**：最大容量 25个，箱规 24个/箱

## 📝 文件格式要求

### 交易记录文件 (必需)
- 格式：Excel (.xlsx, .xls)
- 第1列：销售时间 (SaleTime)
- 第4列：机器编号 (Machine)
- 第7列：产品名称 (Product)

### 补货历史文件 (可选)
- 格式：Excel (.xlsx, .xls)
- 第1列：补货时间 (RefillTime)
- 第2列：机器编号 (MachineName)

## 🔍 故障排除

### 文件上传问题
- 确保文件格式为 .xlsx 或 .xls
- 检查文件大小不超过 50MB
- 确保网络连接稳定

### 计算结果问题
- 检查机器时间设置是否正确
- 确认产品名称映射是否匹配
- 验证数据格式和列位置

### 容量约束问题
- 红色数字表示超出最大容量
- 调整手动调整值以符合容量限制
- 系统会自动优化智能调整量
