# 智能补货系统 - 生产版本部署指南

## 🚀 快速启动

### 方法一：使用智能启动脚本（推荐）

```bash
# 启动生产服务器（默认端口8080）
python3 start_production.py

# 指定端口启动
python3 start_production.py --port 9000

# 强制终止端口冲突进程
python3 start_production.py --force-kill

# 不自动打开浏览器
python3 start_production.py --no-browser
```

### 方法二：手动启动

```bash
# 1. 先发布项目
dotnet publish -c Release -o ./publish

# 2. 启动静态文件服务器
cd publish/wwwroot
python3 -m http.server 8080
```

## 📋 系统要求

- .NET 9.0 SDK
- Python 3.x
- 现代浏览器（Chrome、Firefox、Safari、Edge）

## 🌐 访问地址

- **本地访问**: `http://localhost:8080`
- **移动设备**: `http://192.168.0.22:8080` （需在同一WiFi网络）

## 📱 功能特性

### ✅ 核心功能
- 📊 Excel文件数据分析（交易记录、补货历史）
- 🧠 智能补货量计算与调整
- 📱 响应式设计，完美适配移动设备
- 🔍 表格缩放功能（50%-200%）
- ⚡ 实时计算和数据验证

### ✅ 表格显示
- **产品信息**: 产品名称 + Max容量 + 箱规信息
- **基础补货**: 基于历史销售数据计算
- **智能调整**: 自动调整量（支持负数显示）
- **手动调整**: 可手动输入调整值
- **总计**: 最终推荐补货量
- **箱数/余件**: 自动计算箱数和余件

### ✅ 视觉优化
- 🎨 颜色编码：负数调整红色，正数调整黄色
- 📐 紧凑布局：移除水平滚动，优化移动体验
- 🔍 缩放控制：默认90%显示，可调节至50%-200%
- ⚠️ 超容量警告：当补货量超过机器容量时红色警告

## 🔧 故障排除

### 端口占用问题
```bash
# 查看端口占用
lsof -i :8080

# 强制清理端口
python3 start_production.py --force-kill
```

### 文件权限问题
```bash
# 给启动脚本添加执行权限
chmod +x start_production.py
```

### 发布目录不存在
```bash
# 重新发布项目
dotnet publish -c Release -o ./publish
```

## 📊 使用流程

1. **上传文件**: 选择交易记录和补货历史Excel文件
2. **检测机器**: 系统自动从交易记录中提取机器列表
3. **设置时间**: 配置每台机器的最后补货时间
4. **计算补货**: 点击"计算补货需求"生成智能推荐
5. **手动调整**: 根据实际情况微调补货量
6. **查看结果**: 获得最终的补货计划（箱数+余件）

## 🎯 性能优化
